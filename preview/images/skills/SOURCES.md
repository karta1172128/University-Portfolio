# 技能標誌來源

原有四項標誌於 2026-11-21 查核並下載，JavaScript 於 2026-11-22 加入，皆使用下列來源當時公開提供的素材；這代表來源核對日期，不宣稱各標誌在此日發布或日後不會改版。
